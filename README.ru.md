# Cat & Mouse

**Дважды в неделю читает поток AI-новостей за меня — и присылает в Telegram одну вещь, с которой стоит что-то сделать.**

*[Read in English →](README.md)*

---

## Проблема

Следить за AI-инструментами в 2026 — это GitHub trending, YouTube-каналы,
release notes, бесконечные треды «топ-10 агентов». Ежедневный просмотр съедает
час и не даёт ничего: список названий репозиториев со звёздочками получает
полсекунды внимания и закрывается.

## Что делает

`digest.py` собирает свежий сигнал с GitHub (поисковые запросы + активность
отслеживаемых репозиториев) и YouTube (через `yt-dlp`, без API-ключа),
отбрасывает всё, что уже присылалось за последние 14 дней, детерминированно
оценивает каждого кандидата, кластеризует уцелевших в **темы**, выбирает одну
самую сильную и отправляет короткий аргумент о ней в Telegram — по вторникам и
субботам в 11:00, через планировщик задач Windows.

Цель: дважды в неделю — **одна вещь, с которой стоит что-то сделать**. Не меню.

## Главное правило, которому научил этот проект

> **Модель сжимает; код судит.**

У локальной 7B-модели (Ollama) здесь ровно одна работа: превратить элемент в
одно читаемое предложение. Она не оценивает релевантность, не выбирает тему, не
пишет вводную строку. Всё три варианта были испробованы — результаты сравнения
лежат в шапке [`local_llm.py`](local_llm.py). Коротко: 7B-модель поставила
треду с 831 комментарием 0/10, а рутинному патчу — 8/10. Сжатие — механическая
задача, и маленькая модель с ней справляется; суждение — нет, и она — нет.

## Как проект к этому пришёл

Начиналось как ежедневный дашборд со ссылками и намеренно сжалось во что-то
меньшее и острее:

| Итерация | Что изменилось | Почему |
|---|---|---|
| v1 — ежедневный дашборд | Список ссылок по категориям каждое утро в 08:55 | Полсекунды внимания, ноль действий |
| v2 — авто-анализ | Вердикт (делать / попробовать / пропустить) после каждого дайджеста; формат ужат на ~40% | Списки не двигают к действию; аргументы — да |
| v3 — шире сеть | Категории, Reddit OAuth, де-дуп за 14 дней, одно уведомление вместо серии | Больше источников, меньше повторов |
| v4 — лента в одну строку | Дайджест переделан в короткую цепкую ленту | Всё ещё меню, просто короче |
| v5 — перестройка | Ежедневно → Вт+Сб 11:00 · дашборд → разбор одной темы · сжатие локальной моделью · Reddit убран, watch-list расширен | Одна тема за запуск, ссылки — как доказательства под тезисом |

Reddit убрали, когда их API-политика закрыла личные read-only приложения —
обоснование задокументировано прямо в [`creators.json`](creators.json), рядом с
конфигом, который оно объясняет.

## Файлы

| Файл | Роль |
|---|---|
| `digest.py` | Сбор → де-дуп → оценка → кластеризация → отправка. Весь конвейер. |
| `local_llm.py` | Обвязка Ollama. Только сжатие — см. главное правило. |
| `send_verdict.py` | Отправляет вердикт после анализа в Telegram. |
| `creators.json` | Watch-list с обоснованием каждого выбора прямо в файле. |
| `verdict_prompt.txt` | Промпт анализа и его строгий формат вывода. |
| `run_morning.ps1` / `analyze_and_notify.ps1` | Точки входа для планировщика задач Windows. |
| `test_dedup.py` | Тесты 14-дневного окна де-дупликации. |

## Запуск

```
pip install -r requirements.txt
cp .env.example .env      # заполните своими значениями
python digest.py --dry-run
```

Переменные окружения (см. [`.env.example`](.env.example)):
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `GITHUB_TOKEN`; опционально
`LOCAL_MODEL` и `OLLAMA_HOST` для шага сжатия — при выключенной Ollama всё
деградирует аккуратно.
